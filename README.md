### 🌍 Global Retail Analytics Dashboard 

End-to-end Business Intelligence project that transforms raw retail sales data into actionable business insights using SQL Server, Power BI, DAX, and Power Query.

**Key Highlights**

- Built a SQL Server Data Warehouse using a Star Schema.
- Designed and implemented ETL processes.
- Created DAX measures and KPIs for business analysis.
- Developed an interactive Power BI dashboard.
- Documented the complete analytics workflow following the Google Data Analytics process.
